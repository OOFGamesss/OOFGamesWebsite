About the Emporium

Mini Games Emporium is the all-in-one hosting tool powering every mini game run at venues. It handles everything a host needs: player queues, session tracking, trade verification, automated chat announcements, and a full transaction ledger, so the host can stay focused on the crowd, not the spreadsheet. Accessed in-game with /mge, the plugin organises every game into its own tab alongside a shared Transaction History ledger and a Settings panel.

Key Features

Player Queue Management

Players join a waitlist by typing a keyword in chat, letting the host run the current session uninterrupted while the next group queues up automatically.

Trade Verification

The plugin opens a trade window with a single click and confirms the exchange, so entry fees and payouts are handled without manual tracking or risk of error.

Automated Chat Announcements

All session messages - start calls, results, win shouts, and queue status - are posted to in-game chat automatically, keeping the crowd informed without host intervention.

Transaction Ledger

Every trade processed through the plugin is recorded with the player name, amount, and timestamp, giving you a full audit trail for the entire event.

Preset Manager

Save your game settings and chat messages as named presets that can be shared across venue staff, ensuring every host runs sessions consistently regardless of who is on duty.

Interface

Mini Games Emporium provides six tabs covering everything from running games to managing settings across your team.

Mini Games

The central hub for all available games. Each game has its own section where you configure entry fees, queue or walk-in mode, and game-specific settings, then run the full session - from taking entries to announcing the result and processing payouts - without switching windows.

Session History

A log of every session run across all games, showing the game type, participants, entry fees collected, and the outcome so you can review any event at a glance or refer back to a specific result later in the evening.

Transaction History

A complete record of every trade opened and completed through the plugin, including the player name, amount, and timestamp, giving you a full audit trail for the night that you can refer to for any payment queries or end-of-event reconciliation.

Preset Manager

Create, edit, and share named presets containing full game configurations - entry fees, queue settings, and chat messages - so venue staff can load a consistent setup in seconds rather than re-entering the same values before each event.

Settings

Plugin-wide preferences covering chat announcement behaviour, trade verification options, and other global toggles that apply across all games. Changes take effect immediately without needing to restart the plugin or reload an active session.

Support

A built-in FAQ covering setup, game configuration, and common troubleshooting. A Discord link connects you directly to the Mini Games Emporium support channel for anything not covered there.

Games

🎰

BAR 777

View details ➔

Players pay an entry fee and use FFXIV's built-in /random command to roll for the winning number. Hit it within the allotted rolls and take home the pot. The plugin watches chat in real time, logs every roll, and fires automated win or unlucky messages without any manual input from the host. Supports both walk-in and queue modes, with a live statistics panel tracking trades taken, players played, and queue length. The pot grows from entry fees plus an optional venue-side boost.

🎲

Deathroll Tournament

View details ➔

A bracket-based elimination game where players register by typing the join keyword in chat and pay an entry fee to be seeded into the bracket. In each head-to-head match, players take turns rolling within the range of the previous roll - the first to hit a 1 loses. The plugin manages registration, power-of-two bracket seeding, best-of series tracking, bye slots, tie-break re-rolls, and all automated announcements from opening bell to champion shout, with a live Discord embed that updates automatically throughout the event.

Commands

  • /minigamesemporium Open the main plugin window.
  • /mge Alias for /minigamesemporium.
  • /mgeconfig Open directly to the Settings tab.

How to install

  1. 1. Type /xlsettings in the in-game chat to open the Dalamud settings window.
  2. 2. Navigate to the Experimental tab.
  3. 3. Paste the following link into the Custom Plugin Repositories field at the bottom:
https://raw.githubusercontent.com/OOFGamesss/OOFGamesPlugins/main/pluginmaster.json
  1. 4. Click the + button, ensure the repository is set to Enabled, then click Save and Close.
  2. 5. Type /xlplugins, search for Mini Games Emporium, and click Install.
