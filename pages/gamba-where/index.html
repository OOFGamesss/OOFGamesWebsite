About the plugin

Gamba Where is a Dalamud plugin that lets players discover active gamba sessions and host their own with configurable rules, presets, and automatic location updates. Browse the live event feed, filter by game type and data centre, and jump straight to the action with optional Lifestream integration.

Key Features

Card-based Event Feed

Browse active sessions as expandable cards showing host, venue, description, and the full rule set at a glance.

Filter by Game Type and Data Centre

Narrow the live event feed using dropdown filters so you only see sessions relevant to where you play and what you want to join.

Host Your Own Session

Run Bingo, Blackjack, Chocobo Racing, and more from a single hosting form with game-specific rule controls that appear automatically for the chosen game type.

Save and Reuse Presets

Store your preferred rule configurations as named presets per game type so recurring events can be spun up in seconds without re-entering the same settings each time.

Background Location Refresh

Your active listing is updated automatically every minute so your venue and rules stay accurate for attendees without any manual intervention.

Auto-detect Rules from Companion Plugins

When SimpleBingo, Simple Roulette, or Chocobo Racing Gamba are installed, rules are read and surfaced as clickable in-game chat prompts attendees can copy directly.

Lifestream Integration

If Lifestream is installed, attendees can travel straight to your venue with a single click on the event card, with no manual address lookup needed.

In-game Alerts

Receive a coloured chat notification whenever a new event matches your saved alert rules for games, data centres, or venues so you never miss a session you care about.

Interface

Gamba Where provides seven tabs covering everything from browsing events to managing alerts.

Gamba Events

The main browsing view. Each event card displays the host's name, venue, description, rule set, and current in-world location. Use the game type and data centre dropdowns at the top of the list to narrow the feed to what interests you. Expand any card for the complete rule detail and a one-click Discord copy button so you can paste the event straight into your server without retyping anything.

Host Gamba

Everything you need to run your own session: select your venue, choose a game - Bingo, Blackjack, Chocobo Racing, Mini Games, and more - write a short description for attendees, and configure game-specific rules that appear automatically for the chosen game type. Presets let you save, rename, update, and delete configurations so you can spin up a recurring event in seconds, while the plugin refreshes your location every minute in the background and, where companion plugins are installed, detects rules automatically and provides clickable chat prompts attendees can copy directly from in-game chat.

Game List

A curated reference of companion plugins that work alongside Gamba Where. Each entry explains what the plugin does, which game types it covers, and how it integrates with the Host Gamba tab. Use it to discover tools that can automate rule detection and chat prompts for your preferred games.

Discord Webhook

Connect a Discord webhook and configure your announcement format without leaving the plugin window. Once set up, the plugin posts to your chosen channel automatically when you start or update a session, keeping your community informed with the latest venue, rules, and location details.

Alerts

Set up in-game chat alerts for specific data centres, games, or venues by clicking + Add alert, naming the rule, and configuring three multi-select rows - Games, Data Centres, and Venues - where choices within a row match any selected value and choices across rows combine with AND. After the first refresh, matching sessions produce a coloured chat line tagged GambaWhere showing game, venue, and host; clicking it opens Gamba Events with the relevant card expanded.

Settings

Adjust how Gamba Where behaves across all tabs. Toggle quest toasts and chat sound effects for alert notifications, configure the events refresh interval, and manage your Lifestream integration preference. Changes take effect immediately without needing to restart the plugin or reload the event feed.

Support

A built-in FAQ covering common setup questions, troubleshooting steps, and companion plugin pairing. For issues not answered here, a Discord link connects you directly to the Gamba Where support channel.

Commands

  • /gambawhere Open the main plugin window.
  • /gw Alias for /gambawhere.
  • /gambawhereconfig Open directly to the Settings tab.

How to install

  1. 1. Type /xlsettings in the in-game chat to open the Dalamud settings window.
  2. 2. Navigate to the Experimental tab.
  3. 3. Paste the following link into the Custom Plugin Repositories field at the bottom:
https://raw.githubusercontent.com/OOFGamesss/OOFGamesPlugins/main/pluginmaster.json
  1. 4. Click the + button, ensure the repository is set to Enabled, then click Save and Close.
  2. 5. Type /xlplugins, search for Gamba Where, and click Install.
