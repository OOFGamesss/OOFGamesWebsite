BAR 777

Roll for the winning number and take home the pot.

How to play

  1. 1. Collect the entry cost from the player before their rolls begin.
  2. 2. The player types /random in chat the configured number of times (roll count).
  3. 3. If they roll the winning number, they win the entire pot.
  4. 4. If they lose, their bet is added to the pot for the next round.
  5. 5. Use Walk-in for smaller venues, or Queue for larger venues with 10 or more players.
  6. 6. Queue players join via a chat keyword and receive an alert when they are coming up next.

Key Features

Walk-in and Queue Modes

Choose Walk-in for drop-in events where players approach the host directly, or switch to Queue mode for larger venues where players join via keyword and are placed in a managed waitlist.

Configurable Win Condition

Set the winning number and the number of /random rolls each player receives per session, giving you full control over game difficulty and pacing.

Boosted Pot

Gil put in by the venue to increase the prize pool, making the event more attractive for attendees.

Next-up Alerts

Players in queue receive an automatic tell when they are coming up next, keeping them engaged without having to hover near the host waiting for their turn.

Queue Persistence

The waitlist survives plugin restarts, so a crash or reload mid-event will not wipe the queue or lose any player's position in line.

Automated Announcements

Six customisable chat templates with auto-send toggles handle payment requests, roll starts, halfway warnings, unlucky outcomes, and win shouts without manual typing.

Custom Chat

Manual Trigger Messages

Start Rolls Sent from the 'Send Start Rolls Msg' button on the Game panel when auto-start is off. Also fires automatically if Auto Start Rolls is enabled.
Request Gil Sent from the 'Request Gil' button on the Game panel to prompt the current player to pay their entry.
Request Gil (Buyer) Sent from the 'Request Gil (Buyer)' button to a third party paying the entry fee on behalf of another player.
Announce Pot Sent from the 'Announce Pot' button on the Stats panel to broadcast the current pot total.
Announce Keyword Sent from the 'Announce Keyword' button in the queue panel to broadcast the join keyword. Queue mode only.
Next Player Up Sent from the 'Next Player Up' button beside the player name on the Game tab to call the next player forward. Queue mode only.

Auto Messages

Halfway Fires automatically when half the player's rolls have been used.
Unlucky Fires automatically when all rolls are used without hitting the winning number.
Win Shout Fires automatically when a win is detected.
Join Queue Sent automatically via tell when a player successfully joins the queue. Not sent if they are already queued. Queue mode only.
Reminder to Play Sent automatically via tell when a player's queue position reaches the configured threshold or below. Sent once per player per session. Queue mode only.

Stats panel

The Stats panel at the bottom of the Game tab tracks live session figures.

Total Pot All entry fees collected plus the boosted pot, updated after each trade.
Boosted Pot Gil put in by the venue to boost the prize pool.
Players Played Number of players who have completed a session so far.
Taken in Trades Total Gil received from players during the current session.
In Queue Players currently waiting in the queue. Visible in Queue mode only.
