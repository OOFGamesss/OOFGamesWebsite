Voting Madness

Say your choice in chat and let the crowd decide.

How to play

  1. 1. Add at least two voting options, choose which chats to listen on, set the vote rules and an optional closing time, then start the session.
  2. 2. Players cast a vote by saying an option keyword as a whole word in an enabled chat channel (Say, Shout, Yell, or Tell). The host's own messages are ignored.
  3. 3. Watch the live colour-coded bar chart and the voter table as tallies update in real time.
  4. 4. When ready, stop the vote. Voting closes and the Vote Ended shout is sent automatically.
  5. 5. Announce the winning vote, or the tie message if two or more options share the lead.
  6. 6. Stop the session to clear the poll and write the result to session history.

Key Features

Keyword Voting from Chat

Players vote by saying an option keyword as a whole word in Say, Shout, Yell, or Tell. The host's messages are ignored so they can shout options without casting a vote.

Live Colour-Coded Bar Chart

Each option gets its own colour and a live bar that grows as votes come in, so the crowd can see the race at a glance.

Voter Table

Every voter appears in a table with their world and vote(s). The host can delete a player's votes if something needs correcting mid-poll.

Flexible Vote Rules

Enable multiple choice so players can pick more than one option, or allow multiple votes so the same option can be cast more than once. With both off, each player gets a single vote.

Optional Closing Time

Set a close time in Server Time to show a live countdown and drive a closing announcement. Voting stays open until the host stops the vote.

Winner and Tie Shouts

After the vote is stopped, announce the winning option or the dedicated tie message when two or more options share the lead.

Custom Chat

Manual Trigger Messages

Announce Options Sent from the 'Announce Options' button on the Game panel to list the voting keywords.
Vote Started Sent from the 'Vote Started' button on the Game panel to tell the crowd voting is open.
Closing Time Sent from the 'Closing Time' button on the Game panel when a close time is set, including the close time and how long is left.
Standings Sent from the 'Standings' button on the Game panel to broadcast the current tallies with percentages.
Vote Ended Sent automatically when 'Stop Vote' is pressed, and available as a button afterwards.
Announce Winning Vote Sent from the 'Announce Winning Vote' button after the vote is stopped, including the winner, share, and vote counts.
Announce Tie Used instead of Announce Winning Vote when two or more options share the lead.

Stats panel

The Stats panel at the bottom of the Game tab tracks the live tallies.

Total Votes Number of votes cast this session.
Unique Voters Number of distinct players who have voted.
Leading Option The option currently ahead, or a tie list when more than one shares the top count.
Time Left Countdown to the configured closing time when one is set. Displays "Closed" once that time has passed.
