Truth or Dare

Run Truth or Dare rounds at your venue without tracking rolls by hand.

About the plugin

Truth or Dare is a Dalamud plugin that opens a timed entry window, records every player's roll, and works out who asks and who answers. Players enter with /random or /dice and the plugin handles the rest: tiebreaks, the countdown, the result, and the announcement. Prompt lists are editable in two ratings, every announcement is a template you can rewrite in your venue's voice, and each message type can be routed to its own chat channel. Settings save into named profiles so a host can move a whole setup between characters or venues.

Key Features

Timed Entry Window

Entry runs for 60 seconds by default, with an automatic warning posted when time is nearly up. Both the window and the warning are configurable.

Automatic Roll Capture

Rolls from /random and /dice are recorded as they land, each independently toggleable, with one roll kept per player and later rolls discarded.

Ties Broken by Arrival Order

Whoever rolled the number first keeps it, so a shared roll never needs a re-roll or a host ruling to settle.

Six Resolution Modes

Highest asks lowest, Highest roller, Lowest roller, Highest and lowest, Middle roller, or Random player, switchable mid-session without leaving the round.

Join Gating

Turn on Require a join and players must type !join first, so rolls from an overlapping bingo or deathroll never land in your round.

Editable Prompt Library

160 truths and dares ship across two ratings, tame and spicy, with your own additions alongside them and the last 15 drawn prompts held back so the same line does not keep coming up.

Fresh Picks Every Round

No-repeat winners pass over anyone picked last round, pass-to-next hands the pick on for anyone who would rather sit one out, and an auto-skip list covers regulars who never want to be chosen.

Jackpot and Bonus Prizes

A jackpot number, 666 by default, overrides the normal result when someone lands it exactly, and bonus prizes on chosen numbers are announced without affecting who is picked.

Fully Editable Announcements

Every line the plugin says is a template with placeholders, so the announcements read in your venue's voice rather than the plugin's.

Per-Channel Message Routing

Rules, countdowns, status, results, prompts, jackpots, and bonus prizes each get their own chat channel, with an optional per-winner channel on top.

Settings Profiles

Save the full game settings and prompt list under a name, then load, import, or export it through the clipboard to move a setup between characters, venues, or co-hosts.

Crash and Reload Recovery

The live round is written to disk as it runs, so a crash or a plugin reload picks the round back up where it left off instead of losing the rolls.

How a round runs

  1. 1. The host starts a round, either from the Round panel or by typing !tod in chat.
  2. 2. The plugin announces the game and opens the entry window, 60 seconds by default.
  3. 3. Players enter with /random. With Require a join switched on they must type !join first, and any unrelated roll is ignored.
  4. 4. One roll is recorded per player. Later rolls from the same player are discarded.
  5. 5. With 10 seconds left, the plugin posts a warning to chat.
  6. 6. When the window closes, the lowest roller picks truth or dare and the highest roller sets the question or the dare.
  7. 7. If nobody can think of anything, either picked player can type !truth or !dare to draw a random prompt from the plugin's list.

Interface

Truth or Dare organises everything through an icon sidebar covering the guide, the round, prompts, profiles, settings, and support.

Guide

A walkthrough of how a round runs, the slash commands, and the chat triggers, so a new host can get going without leaving the game.

Round

Start, watch, and resolve a round. The status card shows the live phase and entry countdown, the rolls table fills as players enter and marks anyone skipped, picked, or holding a bonus, and the result card carries the pick alongside buttons to draw a truth, draw a dare, pass the pick to the next player, copy the result, or cancel the round outright. The resolution controls sit here too, so you can change how the round resolves without opening Settings, and a statistics card tracks both session and all-time counters.

Prompts

Edit the truth and dare lists. Covers the 160 prompts that ship with the plugin and your own additions, filtered by kind and by rating, with controls for the rating drawn from, how many recent prompts to avoid repeating, and whether drawn prompts are posted to chat. Shipped prompts can be hidden rather than deleted, and Restore Hidden brings them all back, so your choices survive future updates to the list.

Profiles

Save, load, and delete named settings profiles. Each profile carries the full game settings and prompt list, and Copy Selected, Copy All, Paste One, and Paste All move them through the clipboard as plain text, so a setup can go to another character or straight to a co-host.

Settings

Manage the plugin from the Settings sidebar group, split into Game, Chat Channels, Announcements, Extras, and UI. Set the entry window and its warning, the minimum number of players, how players enter, and how the round resolves; route each kind of message to its own chat channel and pick which channels chat triggers are read from; rewrite every line the plugin says as a template, with a placeholder reference for each one; switch on the jackpot roll, bonus prizes, the auto-skip list, and the forfeit list; and choose the two theme colours that every other colour in the window is derived from.

Support

A built-in FAQ covering starting a round, why rolls are being ignored, keeping an overlapping game out of your round, editing the prompts, routing messages per channel, testing without spamming the room, and hosting at more than one venue. A Discord link connects you directly to the Truth or Dare support channel for anything not covered there.

Commands

  • /tod Open the main plugin window.
  • /tod config Open directly to the settings section.
  • /todstart Start a round.
  • /todstop Cancel the round in progress.
  • /todstatus Print the current round state to your own chat log.

Chat Triggers

  • !tod Start a round. Restricted to the host by default.
  • !join Register for the round, used when Require a join is switched on. Anyone can use it.
  • !truth Draw a random truth prompt. Available to the players the round picked.
  • !dare Draw a random dare prompt. Available to the players the round picked.

The ! prefix is configurable, and you choose which chat channels the plugin listens to. By default it watches Say, Shout, and Yell.

How to install

  1. 1. Type /xlsettings in the in-game chat to open the Dalamud settings window.
  2. 2. Navigate to the Experimental tab.
  3. 3. Paste the following link into the Custom Plugin Repositories field at the bottom:
https://puni.sh/api/repository/oof-games
  1. 4. Click the + button, ensure the repository is set to Enabled, then click Save and Close.
  2. 5. Type /xlplugins, search for Truth or Dare, and click Install.
