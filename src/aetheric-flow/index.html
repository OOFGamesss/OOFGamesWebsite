Aetheric Flow

Teleport to any map link in chat with one click.

About the plugin

Aetheric Flow is a Dalamud plugin that watches your chat for map links, works out the nearest aetheryte in that zone, and adds a clickable teleport link right after the coordinates. Hunt calls, hunt trains, treasure maps, anything with a map link in it becomes a single click. It measures the real distance from the link's coordinates to every aetheryte in the zone, offers only the crystals you have already attuned to, and teleports through the game's own system with no other plugin required. Teleporting drops a map flag on the destination so it is waiting on your map, minimap, and compass the moment you land, and /aftp does the same job from a macro for anyone playing on a controller.

Key Features

A Teleport Link on Every Map Link

Any chat message carrying a map link gains a clickable link beside it, marked with the aetheryte icon and labelled Teleport to <aetheryte>.

The Nearest Crystal, Every Time

The plugin measures the distance from the map link's coordinates to every aetheryte in that zone and picks the closest one, rather than defaulting to whichever crystal the zone is named after.

Attuned Aetherytes Only

Crystals you have not attuned to are filtered out before the nearest one is chosen, so a teleport link never fails when you click it.

Stays Out of the Way

When a zone has no aetheryte you can reach, the message is left exactly as it was. No error, no placeholder, and no clutter in your chat log.

Quicker on Foot Notice

When you are already in the zone and standing closer to the link than the aetheryte is, a quiet grey Quicker on foot note is added so you do not waste a teleport.

Automatic Map Flag

The destination is flagged as you teleport, so it is on your map, minimap, and compass the moment you land instead of needing the original link opened again.

Controller and Macro Friendly

/aftp teleports to the most recent map link exactly as if you had clicked its link, so a single hotbar macro replaces reaching for the mouse.

Twelve Link Colours

Pick the colour of the teleport link from a row of swatches drawn straight out of the game's own chat palette, so it sits naturally alongside the colours you already use.

Per-Channel Scanning

Choose exactly which channels are watched, from Say, Shout, and Yell through party, alliance, free company, PvP team, novice network, echo, tells in both directions, and all eight linkshells and cross-world linkshells.

City Districts Covered

Districts served only by aethernet shards fall back to the teleportable crystal for that network, so a map link dropped in a city sub-zone still gets a working link.

Four Languages

Every line the plugin writes, from the link label to the settings window, is translated into English, Japanese, German, and French.

No Dependencies

Teleports run through the game's own teleport system. There is no companion plugin to install and nothing to keep in sync.

Interface

The window opens with /aethericflow and holds two tabs. Settings is split into General, Channels, and Appearance. Support carries the FAQ and the Discord link.

Settings: General

Two switches that decide what happens around the teleport itself. Tell me when walking would be quicker adds the grey Quicker on foot note whenever you are in the zone already and nearer the link than the aetheryte is. Place a map flag when I teleport drops the flag on the destination as the teleport fires. Both are on by default, and both apply to clicked links and /aftp alike.

Settings: Channels

A two-column grid of tick boxes covering every channel the plugin can scan for map links: Say, Shout, Yell, incoming and outgoing tells, party, cross-world party, alliance, free company, PvP team, novice network, echo, linkshells 1 to 8, and cross-world linkshells 1 to 8. Everything is enabled to begin with, so switching a channel off is how you keep a busy shout channel or an unrelated linkshell from filling your log with links.

Settings: Appearance

Twelve colour swatches, laid out in two rows of six and read straight from the game's own interface colour table, so the teleport link matches the palette the rest of your chat already uses. The chosen swatch is outlined, and the change applies to every link added from that point on.

Support

A short FAQ covering how to use the plugin, why a particular map link did not get a teleport link, which is almost always a channel switched off or a zone with nothing attuned, and how to report a bug or ask for a feature. A button at the bottom opens the OOF Games Discord.

Commands

  • /aethericflow Open the configuration window.
  • /aftp Teleport to the aetheryte from the most recent map link in chat, exactly as if you had clicked its link.
  • /aethericflowtp Alias for /aftp.

Controller players can drop /aftp into a macro and put that macro on a hotbar. The plugin remembers the most recent map link it added a link to, on any channel you have enabled, and holds that target until a newer map link comes in, so there is no rush to press it. The target is cleared when you log out.

How to install

Aetheric Flow is on the official Dalamud plugin list, so there is no custom repository to add.

  1. 1. Type /xlplugins in the in-game chat to open the plugin installer.
  2. 2. Search for Aetheric Flow.
  3. 3. Click Install.
