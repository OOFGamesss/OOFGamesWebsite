Gamba Where

Find and host FFXIV gambling events near you.

About the plugin

Gamba Where is a Dalamud plugin that lets players discover active gamba sessions and host their own with configurable rules, presets, and automatic location updates. Browse the live event feed, build host profiles, connect through the recruitment board, and jump straight to the action with optional Lifestream integration.

Key Features

Card-based Event Feed

Browse active sessions as expandable cards showing host, venue, description, rules, location, and a Discord copy helper.

Filter by Game Type and Data Centre

Narrow the live event feed using dropdown filters so you only see sessions relevant to where you play and what you want to join.

Host Your Own Session

Run Bingo, Blackjack, Chocobo Racing, Mini Games, Poker, Roulette, Scratchcards, Spin the Wheel, and more from a single hosting form with game-specific rule controls.

Save and Reuse Presets

Store your preferred rule configurations as named presets per game type so recurring events can be spun up in seconds without re-entering the same settings each time.

Host Profiles

Build profiles with a name, bio, avatar image, and the games you run, then attach them to the events you host.

Recruitment Board

Venues can advertise for hosts and hosts can advertise for venues through Find a Venue and Find a Host listings.

Background Location Refresh

Your active listing is updated automatically every minute so your venue, location, and rules stay accurate for attendees without manual intervention.

Auto-detect Rules from Companion Plugins

When Simple Bingo, Simple Roulette, Chocobo Racing Gamba, or Mini Games Emporium are installed, rules are read and surfaced as clickable in-game chat prompts where supported.

Discord Webhook Announcements

Post to your chosen Discord channel when you start or update a session, with a configurable announcement format, session snapshot embed, and optional banner image.

Floating Session Pill

See your active session at a glance with a compact overlay pill while you host.

Lifestream Integration

If Lifestream is installed, attendees can travel straight to the gamba with a single click on the event card. The Lifestream plugin is required for this feature.

In-game Alerts

Receive a coloured chat notification, and optional toast or sound, whenever a new event matches your saved alert rules for games, data centres, or venues.

Booster Perks

Discord server boosters can redeem a booster key to unlock a holographic profile treatment on their host profiles.

Minimap Host Indicators

See hosts running sessions on your minimap with colour-coded markers for each game type. Hover an icon to view the game they are hosting and session details.

Find in Party Finder

Press Find in PF on an event card to locate the host's Party Finder listing and open it in FFXIV. If they do not have one posted, the plugin checks and closes Party Finder for you.

Create Party Finder Listings

Hosts can create a party or alliance listing in Party Finder from their session. Gamba Where opens Party Finder and pre-fills the session info so you can review and adjust everything before posting.

Interface

Gamba Where organises everything through a sidebar covering events, hosting, recruitment, profiles, alerts, settings, and support.

Gamba Events

The main browsing view. Discover active gambling events, refresh data from the API, and use the game type and data centre filters to narrow the feed. Each event card displays the host's name, venue, description, rule set, and current in-world location. Expand any card for full rule and location detail, a one-click Discord copy button, and a Find in PF button to jump to the host's Party Finder listing. Active hosts also appear on your minimap with colour-coded markers; hover an icon to see which game they are running and key session information.

Host Gamba

Everything you need to run your own session: select your venue, choose a game, write a short description for attendees, and configure game-specific rules that appear automatically for the chosen game type. Presets let you save, rename, update, and delete configurations so you can spin up a recurring event in seconds. While your session is active, the plugin refreshes your location and rules every minute in the background. Where companion plugins are installed, rules are detected automatically and surfaced as clickable chat prompts. Hosts can also create a party or alliance listing in Party Finder from here; Gamba Where opens Party Finder and pre-fills your session details so you can double-check everything before posting.

Game List

A curated reference of companion plugins that work alongside Gamba Where. Browse what each plugin does and how it fits your events, and discover tools that can automate rule detection and chat prompts for your preferred games.

Recruitment

Expand Recruitment in the sidebar to reach Find a Venue and Find a Host. Find a Venue lets hosts browse and post listings looking for a venue to run at. Find a Host lets venues browse and post listings looking for a host.

Profiles

Create, edit, and delete local host profiles. Each profile carries a name, a bio, an avatar image, and the games you run, and can be attached to the events you host. Discord server boosters can redeem a booster key under Settings to unlock a holographic profile treatment.

Alerts

Set up in-game chat alerts for specific data centres, games, or venues by clicking + Add alert, naming the rule, and configuring three multi-select rows: Games, Data Centres, and Venues. Leave a row on Any if you do not want to filter on that axis. Within one row, choosing several values means match any of these; across rows, filters combine with AND. Each rule needs at least one concrete choice somewhere. After the first events refresh, matching sessions produce a coloured chat line tagged GambaWhere with game, venue or location, and host. Click that line to open Gamba Events with the relevant card expanded. Optional quest toasts and chat sound effects are on the Settings tab.

Settings

Manage the plugin from the Settings sidebar group, split into UI, Chat, Discord Webhook, Booster Key, and Other. Toggle quest toasts and chat sound effects for alert notifications, configure the events refresh interval, manage your Lifestream integration preference, set up Discord webhooks for session announcements with optional banner images, and redeem a booster key for holographic profile treatment. Changes take effect immediately without needing to restart the plugin.

Support

A built-in FAQ covering common setup questions, troubleshooting steps, and companion plugin pairing. For issues not answered here, a Discord link connects you directly to the Gamba Where support channel.

Commands

  • /gambawhere Open the main plugin window.
  • /gw Alias for /gambawhere.
  • /gambawhereconfig Open directly to the settings tab.

How to install

  1. 1. Type /xlsettings in the in-game chat to open the Dalamud settings window.
  2. 2. Navigate to the Experimental tab.
  3. 3. Paste the following link into the Custom Plugin Repositories field at the bottom:
https://puni.sh/api/repository/oof-games
  1. 4. Click the + button, ensure the repository is set to Enabled, then click Save and Close.
  2. 5. Type /xlplugins, search for Gamba Where, and click Install.
